# ridvan.dev

Personal blog powered by [Astro](https://astro.build) using the [astro-chiri](https://github.com/the3ash/astro-chiri) theme by Chiri.

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## 📝 Writing Posts

Create a new post:

```bash
npm run new
```

Posts are located in `src/content/posts/`. Use Markdown (`.md`) or MDX (`.mdx`) format.

## ⚙️ Configuration

Customize your blog in `src/config.ts`:

- Site information (title, author, description)
- Layout settings
- Date format
- Post features (reading time, table of contents, etc.)
